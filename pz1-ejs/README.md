# Road Help — ПЗ1: Middleware и шаблонизаторы (EJS)

Практическое занятие №1. Приложение на Express с шаблонизатором EJS: список заявок на помощь,
детальная страница, форма добавления, страницы ошибок 404 и 500.
Данные хранятся в массиве в памяти (без базы данных).

## Запуск

```bash
cd pz1-ejs
npm install
npm run dev
```

Приложение откроется на `http://localhost:3005` (порт можно изменить переменной `PORT`).

## Структура

```
pz1-ejs/
├── server.js              настройка Express, EJS, маршруты, подключение middleware
├── data.js                массив заявок в памяти и функции работы с ним
├── middleware/
│   ├── logger.js          логирование метода, URL, времени и длительности запроса
│   ├── auth.js            имитация авторизации (?auth=1, cookie) и защита /add
│   └── errors.js          обработка 404 и 500 с рендером страниц
├── views/
│   ├── partials/header.ejs  общий каркас: head, шапка с навигацией
│   ├── partials/footer.ejs  подвал
│   ├── index.ejs          главная: список заявок и статистика
│   ├── item.ejs           детальная страница заявки
│   ├── add.ejs            форма добавления
│   ├── login.ejs          страница входа
│   ├── 404.ejs            страница «не найдено»
│   └── 500.ejs            страница «ошибка сервера»
└── public/styles.css      статические стили (подключены через express.static)
```

## Маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | / | список заявок и статистика |
| GET | /item/:id | детальная страница заявки |
| GET | /add | форма добавления (только для авторизованных) |
| POST | /add | добавление заявки в массив, редирект на карточку |
| GET | /login | страница входа |
| GET | /error | демонстрация обработки 500 |

## Middleware

- **logger** — выводит в консоль метод, URL и время начала запроса, а после ответа — статус и длительность;
- **auth** — при `?auth=1` ставит cookie и устанавливает `req.user = { name: "Диспетчер", role: "admin" }`,
  иначе пользователь остаётся «Гостем»;
- **requireAuth** — не пускает гостя на `/add`, перенаправляя на `/login`;
- **notFound** — рендерит `404.ejs` со статусом 404;
- **errorHandler** — ловит ошибки (четыре аргумента), логирует и рендерит `500.ejs` со статусом 500.

## Проверка

1. `http://localhost:3005/` — список заявок и статистика.
2. `http://localhost:3005/item/1` — детальная страница.
3. `http://localhost:3005/add` — гость будет перенаправлен на `/login`.
4. `http://localhost:3005/?auth=1` — войти как диспетчер, после этого `/add` открывается.
5. Создать заявку через форму — новый элемент появится в списке.
6. `http://localhost:3005/item/999` — страница 404.
7. `http://localhost:3005/error` — страница 500.
