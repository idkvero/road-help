# Road Help — сервис для эвакуации и помощи на дорогах

Курсовой проект по дисциплине «Интернет-технологии и веб-программирование».
Состоит из серверной части (Node.js + Express + PostgreSQL + Sequelize + JWT)
и клиентской части (React + Vite + axios).

## Возможности

- регистрация и вход пользователей, хранение JWT, роли `admin` и `user`;
- создание заявок на помощь (описание проблемы, местоположение);
- водитель видит и редактирует только свои заявки, администратор — все;
- смена статуса заявки администратором: `new` → `in_progress` → `completed`;
- поиск заявок по описанию на сервере с задержкой 500 мс после ввода;
- фильтр по статусу и сводка по количеству заявок;
- оптимистичное обновление интерфейса с откатом при ошибке;
- состояния загрузки, ошибки (с кнопкой «Повторить») и пустого списка.

## Структура

```
road-help/
├── server.js              точка входа сервера
├── config/                конфигурация подключения к PostgreSQL
├── routes/                маршруты REST API (/requests, /auth)
├── controllers/           логика обработки запросов
├── middleware/            проверка JWT-токена и роли
├── models/                модели Sequelize (User, Request)
├── migrations/            миграции структуры базы данных
├── seeders/               тестовые данные
└── client/                React-приложение
    ├── src/api.js         запросы к серверному API (axios + токен)
    ├── src/RequestList.jsx  основной компонент (список заявок)
    ├── src/LoginForm.jsx    вход и регистрация
    └── src/App.css, src/index.css  стили
```

## Запуск

Требуется Node.js и запущенный PostgreSQL с базой `road_help`.

**1. Серверная часть** (порт 3000):

```bash
cd road-help
npm install
npx sequelize-cli db:migrate
npm run dev
```

Параметры подключения к базе — в `config/config.json`, секрет для подписи токенов — в файле `.env` (`JWT_SECRET`).

**2. Клиентская часть** (порт 5173):

```bash
cd road-help/client
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`, адрес API задаётся в `client/.env` (`VITE_API_URL`).

## Основные маршруты API

| Метод | Маршрут | Доступ | Назначение |
|---|---|---|---|
| POST | /auth/register | все | регистрация |
| POST | /auth/login | все | вход, выдача JWT |
| GET | /requests | с токеном | список заявок (админ — все, водитель — свои) |
| GET | /requests/:id | с токеном | одна заявка (своя или любая для админа) |
| POST | /requests | с токеном | создание заявки |
| PUT | /requests/:id | с токеном | изменение (статус меняет только админ) |
| DELETE | /requests/:id | с токеном | удаление (своей или любой для админа) |

Поиск: `GET /requests?search=колесо`.
